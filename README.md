# Water Goddess｜水神的指引

3D 森林冒險遊戲，改編自亞榮隆‧撒可努〈水神的指引〉（收錄於《山豬‧飛鼠‧撒可努2：走風的人》），國中國文課堂用。南一書局 × 林威宇老師製作。

**線上遊玩：** https://weiyu168.github.io/Water-Goddess/

## 玩法

- 電腦：W A S D 移動、滑鼠看四周（先點畫面）、E 或左鍵互動、按住 Q 或右鍵「用心聆聽」（要站著不動）。
- 手機／平板：按住左下角圓形方向鈕移動、右半邊拖曳看四周；右下角「互動」代替 E、「聆聽」代替 Q，按住「快走」搭配方向鈕可加速。也保留左半邊拖曳移動；對話與選項直接點選。建議橫放裝置。
- 一輪約 20 分鐘；標題畫面「章節選擇」可以直接跳到任一章；網址加 `#ch6` 直接開第六章（`#ch1`～`#ch7`、`#end`）。

## 內容

七章＋結語閱讀理解（8 題）：夜露、黃藤小徑、水源區、老獵人的約定、夠用就好、水是甜的（天快亮）、回家的山徑（日出）。
背景音：標題、第一與第二章保留深夜蟲鳴錄音；從第三章「水源區」到第七章與結語，改為循環播放〈Night Forest Search〉。貓頭鷹、蛙鳴為錄音；瀑布、水聲等為即時合成。

`index.html` 是單一檔案（three.js 與音檔都已內嵌），可離線開啟。

## 300 人課堂使用

- 每位學生透過同一網址，在各自裝置上獨立遊玩；進度儲存在各自瀏覽器，不共用世界或存檔，也不需登入。
- 遊戲運算在裝置端執行，沒有遊戲伺服器的連線名額。單檔約 12.35 MB，300 台裝置首次各載入一次約 3.71 GB（未計傳輸壓縮與另外載入的字型）；載入後不需持續下載遊戲場景或音效。
- 保留原 GitHub Pages 網址與 `main` 分支根目錄發布設定。GitHub Pages 每月軟性流量限制為 100 GB，且可能限流，沒有 300 人同時載入的服務保證：[官方限制](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)。
- 上課前可分批開啟網頁，降低 300 台裝置同時下載對校園 Wi-Fi 的負擔。手機／平板自動畫質預設為「流暢」，可在選單調整。

此發行版直接在單檔加入圓形觸控操作與第三章起的音樂切換；若從原始 `water-spirit/src/` 重新建置，須同步保留這些修改。
