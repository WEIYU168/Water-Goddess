# 水神的指引

3D 森林冒險課堂遊戲，改編自亞榮隆・撒可努〈水神的指引〉。

## 線上遊玩

[開啟遊戲](https://weiyu168.github.io/Water-Goddess/)

電腦：W A S D 移動、滑鼠看四周、E 或左鍵互動，按住 Q 或右鍵聆聽。Esc 可解除滑鼠鎖定。

手機／平板：左半邊拖曳移動、右半邊拖曳看四周，使用畫面上的互動與聆聽按鈕。

標題畫面可選擇章節；結語包含閱讀理解測驗。點擊「開始旅程」後啟用聲音。

## 部署與更新

GitHub Pages 從 `main` 分支根目錄部署。`index.html` 是完整遊戲，已內嵌 3D 程式與音效。更新時以新版完整遊戲替換此檔並推送即可。
